Global writing rules (injected into every prompt by `src/prompt_loader.py`):

- All prose you write — summaries, findings, explanations, and every markdown document you generate — must use simple, plain language that a non-technical reader with 1 year of experience can follow. Avoid jargon; when a technical term is unavoidable, explain it in one short line.
- Be as brief as possible in prose: use the shortest wording that keeps the meaning. No filler, no repetition.
- These rules apply to prose only, NOT to code: source code, tests, identifiers, commands, config, and JSON/schema fields follow their own conventions and schemas, unchanged.
- Brevity never deletes substance: every required section, field, finding, and list item must still be present — shorten the wording, never the content.
